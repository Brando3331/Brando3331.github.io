	Описание проекта
SKillboost — это веб-приложение, разработанное на чистом HTML/CSS/, предназначенное для хранения и отображения задач по программированию разного уровня сложности. Проект ориентирован на студентов, разработчиков и самоучек, которые хотят систематизировать свои практические задания по различным языкам программирования.


	Цель проекта
Создать удобную платформу для хранения и визуализации задач, которая может использоваться как личный задачник или как часть портфолио для демонстрации навыков фронтенд-разработки.


	 Основные особенности
Категоризация задач по языкам: JavaScript, Python, C++, и другие.

Разделение по уровням сложности: от базовых до продвинутых.

Интуитивный интерфейс: простой и понятный дизайн.

	Что будет добавлено?
Локальное хранение: задачи сохраняются в браузере с помощью localStorage (если реализовано).

Поиск и фильтрация: возможность быстро находить нужные задачи по ключевым словам или тегам.

Искуственный Интеллект: Задачи будут создаваться посредством AI агента

И самое главное - адаптация под разные устройства
